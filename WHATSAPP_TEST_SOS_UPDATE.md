# WhatsApp TEST SOS update

This backend update adds `TEST` to the accepted alert types. Deploy this backend update to Render before using the Android Profile > WhatsApp SOS test button.

For a custom template with body parameters enabled, TEST is rendered as:
`TEST SOS - NOT A REAL EMERGENCY`.

With Meta's `hello_world` template and body parameters disabled, Meta sends its standard test template; it still verifies the Cloud API delivery path.
